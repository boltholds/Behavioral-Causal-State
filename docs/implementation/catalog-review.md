# Проверка текстового каталога: 2026-10-04

Проверка выполнена исследовательским ассистентом по исходным FAMILIES и реально созданным данным. Human review остаётся `pending`; автоматическая проверка и этот документ не меняют этот статус. Каталог и уже опубликованные dataset hashes сохранены.

Проверены 4 семейства × 6 modes × explicit/implicit time: 48 форм. Имена произвольны внутри указанного словаря, `R/M/C/Y`, `start/stop` остаются буквальными символами контролируемого языка.

| Mode | Значение записи | Результат проверки |
|---|---|---|
| Observation | Получено бинарное измерение в названный момент | Не задаёт вмешательство |
| Unknown | Эта запись не содержит нового измерения | Не утверждает, что прошлые знания утрачены |
| Executed | Команда выполнена; physical clock увеличивается | Отличается от обсуждения и отказа |
| Forced | Значение установлено внешним воздействием | Single-target do, physical clock увеличивается |
| Hypothetical | Команду только рассмотрели/обсудили | Не выполняется и не меняет clock |
| Denied | От новой предложенной команды отказались | Отрицание относится к этой попытке, прошлые исполнения сохраняются |

Имена вводятся в первых двух сообщениях: измерение C на t=0 у первого устройства, затем у второго. В этом benchmark `device-0` означает первое введённое устройство, `device-1` — второе. Имена не имеют постоянного номера между историями. Начальные введения сохраняются во всех семи challenge transforms. Нейронной ветке не передаётся names→ID sidecar; задача binding требует запомнить имена из начальных сообщений.

При implicit time времена выводятся из порядка записей: только Executed/Forced продвигают clock. Остальные записи относятся к текущему срезу. Time challenge сохраняет explicit timestamps при перестановке рассказа. Удаление timestamps здесь сделало бы пару неоднозначной, поэтому запрещено.

Ограничения: контролируемый русский, фиксированные словари и короткие сообщения; нет местоимений, сложной области отрицания, вложенных гипотез или пропущенных initial introductions. Результат на этих текстах не подтверждает grounding свободной речи. Связь первого упоминания с номером сущности — соглашение стенда, не обнаружение сущностей.

Перед полным L1 человек должен проверить эти 48 форм и соглашения времени/binding, зафиксировав решение относительно SHA256 каталога. До этого запускаются только диагностика кода и явно помеченное ограниченное обучение.
