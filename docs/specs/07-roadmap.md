Нумерация ниже — версия этого документа. Направления частично ортогональны: fixed-data допускает do/CF; TTT уже допускает скрытое внутреннее состояние детерминированного автомата. ## Общий критерий закрытия уровня

Будущий уровень MUST иметь versioned fixture/query manifest до открытия test. По умолчанию максимум 3 validation configurations × 5 final seeds, кроме явно заданных R0/P1; после бюджета итог passed/failed/invalid. Нет автоматического «ещё нескольких экспериментов до успеха». Непройденный gate не запрещает исследовать другой ортогональный трек, но запрещает заявлять уровень достигнутым.

Пороги R1–R8 — плановые engineering gates. До реализации соответствующего генератора не существует утверждения, что данные/метрики уже собраны. Для continuous этапа bounds измеряемой области должны быть зарегистрированы; вне неё перенос не заявляется.

## Assumptions не включаются одним пакетом

- Causal Markov связывает graph и factorization; Markov state для динамики — отдельное свойство representation.
- Faithfulness нужна для выводов некоторых conditional-independence discovery методов. Deterministic/XOR cancellations способны её нарушать; такие fixtures нельзя объявлять неудачей PC без проверки assumptions.
- Causal sufficiency исключает скрытых общих причин; FCI/PAG или явный latent class используются при другом assumption set.
- Ignorability относится к assignment при заданном adjustment set; randomized intervention предоставляет иной источник идентификации.
- Positivity нужна в конкретных контекстах целевого запроса. Наблюдательная поддержка не обязана включать физически выполнимый эксперимент, но observational estimator не должен экстраполировать без предположений.
- Modularity, consistency, отсутствие неучтённой interference и noise invariance задаются для каждого режима. Два устройства v0.1 независимы по конструкции.

## Масштаб и замена полного перебора

Для n переменных и до d родителей число локальных parent sets не больше n·∑ₖ₌₀ᵈ C(n−1,k). При d=3: n=8 →512; 12 →2784; 20 →23200; 50 →982500. Это не число глобальных DAG и не число SCM. Fixed binary graph требует n·2^d Bernoulli CPT параметров в верхней оценке; CF response types значительно богаче.

Known temporal order позволяет отделять часть локальных задач; latent coupling и глобальные ограничения могут вновь связывать их. После исчерпания exhaustive budget: candidate screening, type sharing, order/beam search, ILP для малых задач, differentiable structure proposals с дискретной проверкой. Pruning даёт поиск в уменьшенном классе; bounds по нему не переносятся на полный класс без certificate.

Нет универсального порога «после 20 переменных невозможно»: стоимость зависит от d, числа временных срезов, latent noise class, алфавитов и запроса. Каждый scaling report указывает эти параметры, timeout и число оценок. TTT polynomial по числу минимальных состояний не означает polynomial по числу объектов.

## Открытые риски

Сохранение совместного coupling при abstraction; устойчивое выделение переменных из текста; неопределённость partial grounding; взрыв ретроспективного CF archive; поддержка новых объектов без перепутывания идентичности; distinction между неполным solver и пустым классом; перенос после незаметной смены observation function. Каждый риск должен стать отдельным ablation, а не дополнительным скрытым assumption.
