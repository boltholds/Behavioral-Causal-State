# SPEC-09 — G2-MISSPEC: проверка нарушения предположений

Статус: specified_not_run. [Конфигурация](../../experiments/protocols/misspecification-v0.1.json), [аналитические вероятности](../../experiments/fixtures/causal-oracles-v0.1.json).

G2 проверяет поведение причинного ядра с oracle grounding при неверном классе моделей. G0 проверяет корректность simulator/evaluator, G1 — данные и утечки. Прохождение G0/G1 не означает прохождение G2. G2 обязателен для приёмки C1 и утверждений об обнаружении misspecification; ограниченный детерминированный L1 может оцениваться отдельно.

## Assumptions и проверяемые классы

Один целевой объект; R,C задаются реальными do, наблюдается Y, естественное M скрыто. Достоверные interventions и observation map, стационарность noise law между четырьмя клетками, iid reset episodes и известная форма уравнений:

M=R XOR N_M; Y=(M AND NOT C) XOR N_Y.

- H_ind: N_M и N_Y независимы, Bernoulli параметры a,b∈[0,1].
- H_joint: произвольное совместное распределение (N_M,N_Y) на четырёх бинарных исходах, инвариантное между do-клетками.

H_ind⊆H_joint. Диагностические классы намеренно допускают весь закрытый диапазон [0,1]; ограничение p<0.5 из положительного learned-XOR CF класса здесь не требуется. Поэтому отклонение такого более широкого класса не опирается на выбор знака механизма через p<0.5. Корреляция шума между временем и объектами не входит в этот контроль.

## Три generating regimes

Во всех режимах маргинальные Bernoulli noise probabilities 0.1. Independent XOR соответствует H_ind; Shared XOR использует N_M=N_Y; Wrong gate использует независимые шумы, но Y=(M AND C) XOR N_Y.

| do(R=r,C=c) | Independent XOR | Shared XOR | Wrong gate |
|---|---:|---:|---:|
| 0,0 | 0.18 | 0 | 0.10 |
| 0,1 | 0.10 | 0.10 | 0.18 |
| 1,0 | 0.82 | 1 | 0.10 |
| 1,1 | 0.10 | 0.10 | 0.82 |

Все числа — P(Y=1). Это population fixtures, не результаты конечных выборок.

| Истинный режим | H_ind | H_joint |
|---|---|---|
| Independent XOR | Совместим | Совместим |
| Shared XOR | Несовместим | Совместим |
| Wrong gate | Несовместим | Несовместим |

«Совместим» означает наличие модели с этим доступным законом. Это не доказательство, что истинная система удовлетворяет всем assumptions.

## Точный feasibility check для этих классов

Обозначим p_rc=P(Y=1|do(R=r,C=c)), x=p_00, b=p_01. Оба класса требуют p_10=1−x и p_11=b.

Для входных ограничений I_rc=[l_rc,u_rc] вычислить:

X=I_00 ∩ [1−u_10,1−l_10], B=I_01 ∩ I_11.

Для H_joint условие непустоты X и B необходимо и достаточно. Свидетель для выбранных x∈X,b∈B: взять D~Bernoulli(x), N_Y~Bernoulli(b) независимо и N_M=N_Y XOR D. Это создаёт нужные x,b и общий шумовой закон во всех do-клетках.

Для H_ind дополнительно x=b+(1−2b)a, a∈[0,1]. Для фиксированного b достижимый x лежит в [min(b,1−b),max(b,1−b)]. Эти интервалы вложены, поэтому для B=[b_low,b_high] их объединение равно [m,1−m], где m=min(b_low,1−b_high).

H_ind совместим тогда и только тогда, когда X,B непусты и X∩[m,1−m] непусто. Для свидетеля выбрать край B, наиболее удалённый от 0.5, затем x из указанного пересечения и a=(x−b)/(1−2b). При b=0.5 требуется x=0.5, тогда можно взять a=0.

Таким образом, для G2 не нужен эвристический discovery solver: certificate — проверяемые пересечения интервалов и, при совместимости, параметры свидетеля. Реализация MUST проверять certificate независимо от поискового модуля. Параметры witness MUST снова воспроизводить все четыре probability intervals.

## Конечные данные и уровень ошибки

- 10 000 независимых reset episodes на каждую из 4 do-клеток в каждом из 3 regimes.
- 100 seeds: 0,…,99. Один seed задаёт полный panel из 120 000 episodes. Всего 12 000 000 episodes; это отдельный oracle эксперимент, без обучения языковых веток.
- Для каждой клетки строится двухсторонний Clopper–Pearson interval с cell miscoverage α_cell=0.05/(3·4); по α_cell/2 на каждый хвост. Это одновременный 95% coverage всех 12 истинных клеточных вероятностей внутри seed.
- Для нулевого/полного числа успехов применяются соответствующие граничные определения интервала. Endpoints округляются наружу; численные операции не должны искусственно сужать исходные constraints. Fixture tolerance=10⁻¹² не заменяет статистический интервал.
- На тех же intervals проверяются оба класса. Дополнительного Bonferroni за два класса не требуется для statement «все истинно совместимые классы сохранятся при одновременном покрытии клеток»: это детерминированное следствие одного coverage event. Не заявляется 95% simultaneous coverage по всем 100 seeds.

Пустое пересечение означает CertifiedInfeasible со scope=FiniteDataConstraints: заданный класс отклонён на основании confidence constraints. Это статистическое отклонение при declared sampling assumptions, а не безусловное доказательство неверности реального мира.

Если вычисление intervals/certificate не завершено или rounding bounds не проверены, возвращается NotEstablished с computation=BudgetExhausted/NumericalFailure. Отсутствие найденной особи не заменяет проверку пересечений.

## Приёмка G2

1. **G2-EXACT:** вся population compatibility matrix воспроизводится на точечных intervals из fixtures. Все выданные свидетели и infeasibility certificates проверяются; ошибок 0.
2. **G2-POWER:** для каждой из трёх несовместимых клеток compatibility matrix не менее 95/100 finite-data отклонений.
3. **G2-FALSE-REJECTION:** для каждой из трёх совместимых клеток не более 10/100 отклонений. Публикуются все counts и двухсторонние 95% binomial intervals; engineering threshold 10/100 не называется номинальным α теста.
4. **G2-STATUS:** fault injection исчерпывает бюджет до завершения certificate. Без ранее проверенного доказательства возвращается NotEstablished, а не CertifiedInfeasible/ProvenIdentified. Ошибок статуса 0.
5. **G2-UNDETECTABLE:** M₊/M₋ проходят одинаковые observational/do constraints. Движок не объявляет нарушение coupling обнаруженным по этим данным и не выдаёт уникальный CF в полном response-type классе. Sharp CF bounds [0,1], либо честный незавершённый статус до их доказательства.

G2 в целом passed только при прохождении всех пяти частей. Неуспех обнаружить произвольное сколь угодно малое нарушение не оценивается этими power thresholds: они относятся к трём конкретным generating regimes.

## Обязательный отчёт

Seed, counts каждой клетки, confidence intervals, declared class ID, verdict, certificate/witness, computation status, elapsed budget, false-rejection/power summaries. Отдельно указать, что отклоняется совокупность assumptions: данный тест сам по себе не локализует единственную физическую причину несогласия.

Individual p-values не вычисляются. При необходимости они потребуют отдельного null hypothesis и протокола; границы идентификации сами по себе p-value не имеют. [Реестр отложенного](deferred.md).
