# SPEC-06 — Популяция SCM, свидетели и границы

## Назначение

Популяция — проверенное найденное подмножество класса совместимых моделей. Она не является полным классом и не становится Bayesian posterior только из-за мутаций/отбора. Частоты особей не интерпретируются как вероятности истинности механизмов.

Пусть ℓ=inf_C q(M), u=sup_C q(M), P⊆C. Тогда ℓ≤ℓ_P=min_P q≤u_P=max_P q≤u. Интервал [ℓ_P,u_P] называется WitnessRange. В несвязном пространстве даже внутренние точки этого интервала могут не быть достижимыми ответами; хранятся конкретные модели.

Внешние сертифицированные границы L,U обеспечивают L≤ℓ≤ℓ_P≤u_P≤u≤U. Computational gaps: ℓ_P−L и U−u_P. Положительный найденный разброс доказывает неоднозначность в declared scope; нулевой не доказывает идентификации. Для population nonidentification свидетели должны иметь одинаковые доступные популяционные распределения, а не просто проходить finite-data goodness-of-fit.

## Архитектура поиска

CandidateProposer → FeasibilityVerifier → WitnessArchive. Отдельный BoundCertifier обрабатывает полный declared class или сертифицированную релаксацию. Не прошедшие verifier особи могут использоваться внутренним proposal search, но не входят в WitnessArchive.

Допустимость и качество proposal разделяются. Штраф сложности не удаляет совместимую модель из итогового класса, если ограничение сложности не объявлено assumption. Novelty считается только между допустимыми моделями. Для каждого scalar q обязательны baseline min q и max q с теми же ограничениями и бюджетом.

Генотип расширенного будущего поиска: граф/parents, structural functions, совместный noise law или response-type law, observation map. При d бинарных родителях 2^(2^d) возможных deterministic response functions; d=3 даёт 256, а не восемь свободных CF-параметров. CPT не определяет coupling. Если допускаются скрытые confounders, независимые локальные response-type распределения недостаточны.

Мутации: add/remove/swap parent в пределах known order/degree; смена семейства f; изменение параметров/совместного noise law; coupling mutation с сохранением интервенционных маргиналов. Доступные физические interventions не мутируют. Unknown intervention execution требует отдельной модели происхождения событий.

При новых данных особи переоцениваются, архив переносится только после проверки в новом snapshot. Простое пересчитывание fitness не восстанавливает ранее потерянные альтернативы: нужны новые proposals/restarts. Отсутствие допустимых особей означает search failure/not established; CertifiedInfeasible выдаёт только доказавший несовместимость модуль.

## P1 — точный одномерный контроль

Данные задают p₀=P(Y₀=1)=1/4, p₁=P(Y₁=1)=3/4; A рандомизировано независимо от response type U=(Y₀,Y₁). Все совместимые распределения параметризуются t∈[0,1/4]:

| U | P(U) |
|---|---:|
| 00 | t |
| 01 | 3/4−t |
| 10 | 1/4−t |
| 11 | t |

Запрос q=P(Y₁=1|A=0,Y=1)=4t имеет sharp bounds [0,1]. Все особи одинаково хорошо объясняют доступные observational/do laws. M₋: t=0; M₊: t=1/4. Средняя точка t=1/8 даёт q=0.5, но не получает привилегированного статуса.

Настройки: [population-v0.1.json](../../experiments/protocols/population-v0.1.json). 64 особи, initial t~Uniform(0.10,0.15); 100 поколений по 64 новых кандидата; 100 seed. Мутация t′=clip(t+Normal(0,0.025²),0,0.25). Crossover отсутствует. Clipping создаёт атомы на границах, поэтому его влияние явно учитывается при интерпретации.

| Arm | Proposal и selection |
|---|---|
| fit_only | 64 uniform-parent mutations; из parents+offspring случайно выбрать 64, так как все fit score равны |
| novelty | Те же mutations; выбрать 64 farthest-first по abs(q_i−q_j); первая особь — минимальный stable candidate ID, ties по ID |
| directed | Две популяции по 32, одна min q, другая max q; по 32 mutations, rank-select лучшие 32 из parent+offspring каждой |
| uniform | После тех же 64 initial candidates делать 64 независимых Uniform(0,0.25) кандидата за шаг |

Во всех arms один отдельный архив сохраняет минимальный и максимальный q среди ВСЕХ проверенных кандидатов, а не только выживших. Parent sampling равномерно с возвращением. Семена начальной популяции совпадают между arms; разные RNG streams proposal/selection. Число оценок в каждом arm=64+100·64=6464, включая initial; feasibility checks и query evaluations учитываются отдельно. Повторные кандидаты не дают бесплатных оценок в primary budget; cache speedup только дополнительная wall-time метрика.

### Приёмка P1

- По обоим краям: q_min≤0.01 и q_max≥0.99 минимум в 95/100 seeds.
- Все свидетели удовлетворяют нормировке, неотрицательности и заданным маргиналам с tolerance 10⁻¹².
- Ни один единогласный/пустой набор не маркируется доказательством идентификации/несовместимости.
- Публикуются evaluations-to-both-endpoints, trajectory найденной ширины, endpoint error и wall time; не только последняя популяция.
- Остановка: полный заданный бюджет; момент первого достижения gate сохраняется. Сходимость fitness не останавливает поиск альтернатив.

Это correctness check, не демонстрация преимущества эволюции. Одномерная задача легко решается аналитически и случайным sampling. Если novelty не лучше других arms, это допустимый отрицательный результат.

### Обязательные дополнительные проверки

1. Монотонность Y₁≥Y₀: P(10)=0, t=1/4, q=1. Ответ условен на monotonicity.
2. Finite data: заменить точные p₀,p₁ одновременными binomial confidence intervals; хранить отдельно sampling uncertainty и coupling ambiguity. При denominator lower bound=0 условный CF не вычисляется как обычная конечная дробь без отдельной domain policy.
3. Несовместимость: сохранить p₀=1/4 и добавить требование P(10)+P(11)=0. Solver должен доказать пустой класс; evolution сообщает лишь отсутствие найденных допустимых моделей.
4. Неполный генотип: класс с одним fixed coupling может совпадать по всем do laws. Его точечный ответ помечается условным на этот класс, а не идентифицированным в полном response-type классе.

## Следующий многомерный эксперимент

RQ: сокращает ли population+novelty certified extremal gaps по сравнению с независимым sampling и multi-start min/max при одинаковых proposal evaluations? Нужен малый discrete класс с LP/polynomial-programming эталоном. До отдельного manifest и exact reference этот этап не запускается; истинная SCM не является обязательной целью восстановления при nonidentification.

TTT задаёт predictive constraints на SCM через общий action/observation interface. TTT-модель без causal lifting не добавляется как ещё одна особь для CF q. Методологический источник: [Duarte et al.](08-literature.md).
